# PROJECT: ReelVault

## Vision
ReelVault is a minimalist personal platform designed as a "second brain" specifically for Instagram Reels. It eliminates the clunky workflow of pasting Reel links into Notes or messaging apps, offering a dedicated, fast, and organized way to save, categorize, and find Instagram Reels for later viewing, research, or action.

## Target Audience
Individuals, creators, researchers, and professionals who frequently discover valuable content on Instagram Reels and need a fast, reliable, and organized system to capture and retain that knowledge.

## Core Tenets
1. **Speed & Simplicity:** Saving a Reel must take seconds. The core flow (Paste -> Save) must be frictionless.
2. **Minimalist Premium Design:** The interface should feel like a modern SaaS productivity application (inspired by Linear, Notion, Arc). 
3. **Data Ownership & Privacy:** The application stores bookmarks, not full copies of content.
4. **Backend-First Quality:** Architecture, database performance, and API security are prioritized over aesthetic frontend work.
5. **Responsiveness:** Fully responsive, mobile-first design.
